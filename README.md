# Project Manager

Внутренний инструмент управления проектами (договоры, этапы, бюджеты, табели).

## Стек
- Go + chi
- PostgreSQL
- HTML / CSS (без внешних фреймворков)

## Локальный запуск
1. `cp .env.example .env` и заполни параметры.
2. `go run ./cmd/server`
3. Открой http://localhost:8080
